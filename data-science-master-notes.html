Introduction to Data Analysis using Excel

15 Hours · Types of analysis → analysis process → cleaning with text/date functions → conditional formatting → sorting, filtering, subtotals

A1Data Analysis & Its Types

Data Analysis is the process of inspecting, cleaning, transforming and modelling data to discover useful information, draw conclusions and support decision-making. Excel is the most widely used entry-level tool because it combines storage (worksheets), computation (formulas), and presentation (charts) in one place.

The six types of data analysis (definition + example = 6-mark question)

TypeWhat it doesExample
Data MiningDiscovers hidden patterns, correlations and anomalies in large datasets using statistics + machine learning + database systems.A supermarket discovers customers who buy bread often buy butter (market-basket analysis).
Business Intelligence (BI)Transforms raw data into meaningful business information for dashboards, reports and strategic decisions.A sales dashboard showing region-wise revenue for management.
Statistical AnalysisCollection, analysis, interpretation and presentation of data using statistics. Two branches: descriptive (summarise — mean, SD) and inferential (conclude about a population from a sample).Average marks of a class (descriptive); exit-poll prediction (inferential).
Predictive AnalyticsUses historical data + statistical models to forecast future outcomes and probabilities.Predicting next quarter's sales from past 5 years' data.
Text Analytics(Text mining) Derives high-quality structured information from unstructured text using linguistic and statistical techniques.Sentiment analysis of product reviews.
Data Analysis with ExcelUsing Excel's built-in features — functions, PivotTables, charts, What-If tools, Power add-ins — to perform all of the above at desktop scale.PivotTable summarising 50,000 sales rows.
Remember the ladder
Descriptive (what happened) → Diagnostic (why) → Predictive (what will happen) → Prescriptive (what should we do). Excel covers the first three well; BI tools extend the last.

A2The Data Analysis Process (6 steps)

  1. Data Requirements Specification — define what data is needed, based on the questions the analysis must answer (inputs: population, variables, units of measurement).
  2. Data Collection — gather data from identified sources: surveys, sensors, transactions, web, databases. Must be accurate and relevant.
  3. Data Processing — organise collected data into a structure suitable for analysis, e.g. rows/columns in a worksheet or table.
  4. Data Cleaning — detect and correct/remove incomplete, duplicate or erroneous records (the step where text functions shine).
  5. Data Analysis — apply techniques (formulas, statistics, visualization, models) to understand, interpret and derive conclusions. Often iterative — may loop back to collection/cleaning.
  6. Communication — report results to users in their required format: tables, charts, dashboards. Visualization (colour coding, charts) makes the message clear.
Exam alert
"Explain the data analysis process" is a guaranteed 8–10 mark question. Draw it as a flow: Requirements → Collection → Processing → Cleaning → Analysis → Communication, with a feedback arrow from Analysis back to Collection.

A3Data Cleaning — Text Functions

Real-world data arrives with stray spaces, wrong case, and values glued together. Excel's text functions fix this without retyping.

FunctionSyntaxPurpose / Example
TRIM=TRIM(text)Removes leading/trailing/extra spaces. TRIM(" data science ") → "data science"
CLEAN=CLEAN(text)Removes non-printable characters (line feeds from imports).
UPPER / LOWER=UPPER(A1)Converts to UPPERCASE / lowercase.
PROPER=PROPER("john doe")Capitalises first letter of each word → "John Doe".
LEFT / RIGHT=LEFT(A1,3)First / last n characters. LEFT("CS1231",2) → "CS"
MID=MID(text,start,n)n characters from position start. MID("CS1231",3,4) → "1231"
LEN=LEN(A1)Number of characters (spaces count!).
FIND=FIND("a",A1)Position of substring — case-sensitive, no wildcards.
SEARCH=SEARCH("a",A1)Same but case-insensitive, wildcards ? * allowed.
SUBSTITUTE=SUBSTITUTE(text,old,new)Replace by content. SUBSTITUTE("a-b-c","-","/") → "a/b/c"
REPLACE=REPLACE(text,start,n,new)Replace by position.

Classic combo
=TRIM(CLEAN(PROPER(A1))) — the one-line clean-up for imported name columns. Also: extract first name → =LEFT(A1, FIND(" ",A1)-1); last name → =MID(A1, FIND(" ",A1)+1, LEN(A1)).

A4Dates & Times

Excel stores every date as a serial number (1 = 1-Jan-1900) and every time as a fraction of a day (0.5 = 12:00 noon). That is why date arithmetic works: =B1-A1 gives days between two dates.

Exam alert
Know how to combine text + date functions: e.g. cell has "Joined: 12/05/2023" → =DATEVALUE(MID(A1,9,10)) extracts and converts the date. This "text functions with date values" pattern is straight from the syllabus wording.

A5Conditional Formatting

Conditional Formatting automatically changes a cell's appearance (fill, font, border, icon) when its value satisfies a condition — making patterns and outliers visible at a glance. Home → Styles → Conditional Formatting.

  • Highlight Cells Rules — greater than, less than, between, equal to, text that contains, a date occurring, duplicate values.
  • Top/Bottom Rules — top 10 items, top 10%, above/below average.
  • Data Bars — in-cell horizontal bars proportional to value (mini bar chart).
  • Color Scales — 2- or 3-colour gradients (e.g., red-yellow-green heat map).
  • Icon Sets — arrows, traffic lights, flags to classify values into 3–5 bands.
  • Formula-based rule — "Use a formula to determine which cells to format", e.g. highlight the whole row where marks < 40: apply =$C2<40 to A2:F100.

Rules are managed (edit/delete/reorder/Stop-If-True) via Manage Rules. Multiple rules can apply to a range; order decides precedence.

A6Sorting & Filtering

Sorting (Data → Sort)

  • Single-level: A→Z / Z→A on one column (or Smallest→Largest for numbers, Oldest→Newest for dates).
  • Multi-level: Sort dialog → Add Level, e.g. by Department, then by Salary descending.
  • Custom sort: by a custom list (Jan, Feb, …), by cell colour, font colour, or icon.
  • Always keep headers checked ("My data has headers") so titles don't get sorted in.

Filtering

  • AutoFilter (Data → Filter, Ctrl+Shift+L): drop-down arrows per column; check-box selection, Text Filters (contains, begins with), Number Filters (greater than, top 10), Date Filters (this month, between).
  • Filter by colour / icon — pairs with conditional formatting.
  • Advanced Filter (Data → Advanced): uses a separate criteria range; supports AND (same row) / OR (different rows) conditions, can copy results to another location, and can extract unique records only.
Sort vs Filter
Sorting rearranges all rows; filtering hides rows that fail the condition — data is not deleted, just hidden.

A7Subtotals with Ranges

The Subtotal command (Data → Outline → Subtotal) inserts automatic summary rows for each group in a sorted list and builds a collapsible outline.

  1. Sort the data by the grouping column first (e.g., Region) — mandatory.
  2. Data → Subtotal → "At each change in: Region", "Use function: Sum", "Add subtotal to: Sales".
  3. Excel inserts =SUBTOTAL(9, range) rows plus a Grand Total, with outline buttons 1/2/3 to collapse or expand levels.

SUBTOTAL(function_num, ref) — function_num 1–11 includes hidden rows; 101–111 ignores them. Key codes: 1/101 AVERAGE, 2/102 COUNT, 4/104 MAX, 5/105 MIN, 9/109 SUM. SUBTOTAL cleverly ignores other SUBTOTAL cells inside its range (no double counting) and, with 9 on filtered data, sums only visible rows.

B1Understanding Lookup Functions

Lookup functions fetch a value from a table by searching for a key — the backbone of joining data in Excel.

FunctionSyntaxNotes
VLOOKUP=VLOOKUP(value, table, col_index, [range])Searches the first column vertically, returns from column col_index. FALSE/0 = exact match (usual), TRUE = approximate (table must be sorted ascending — used for tax slabs, grades). Limitation: cannot look to the left.
HLOOKUP=HLOOKUP(value, table, row_index, [range])Same idea but searches the first row horizontally.
MATCH=MATCH(value, range, 0)Returns the position of a value (0 = exact).
INDEX=INDEX(range, row, [col])Returns the value at a given position.
INDEX+MATCH=INDEX(C:C, MATCH("Ravi", A:A, 0))Flexible lookup — any direction, columns can be inserted safely. Preferred over VLOOKUP.
LOOKUP=LOOKUP(value, lookup_vec, result_vec)Vector form; requires sorted data; approximate match.
XLOOKUP=XLOOKUP(value, lookup_arr, return_arr, [if_not_found])Modern (365/2021): exact by default, any direction, built-in not-found message.
Exam alert
Grade example with approximate VLOOKUP: table {0→F, 40→C, 60→B, 75→A, 90→S} sorted ascending; =VLOOKUP(78, table, 2, TRUE) → "A" (falls back to the largest value ≤ 78). Be ready to write and explain this.

B2PivotTables — Exploring Data

A PivotTable is an interactive summary tool that groups, aggregates and cross-tabulates large datasets without formulas. Insert → PivotTable → choose data → drag fields into four areas:

AreaRoleExample (Sales data)
RowsCategories down the sideRegion
ColumnsCategories across the topYear

  • Grouping: group dates into months/quarters/years; group numbers into bins.

B4Data Validation

Data Validation (Data → Data Validation) restricts what users may enter into a cell — prevention beats cleaning.

  • Allow criteria: Whole Number, Decimal, List (drop-down, e.g. source =$H$1:$H$5 or "Yes,No"), Date, Time, Text Length, Custom (formula, e.g. =ISNUMBER(A1)).
  • Input Message tab: tooltip shown on selecting the cell.
  • Error Alert tab: Stop (reject invalid entry), Warning (allow with confirmation), Information (just inform).
  • Circle Invalid Data flags pre-existing violations in red ovals.

B5Financial Analysis Functions

Convention: money you pay out is negative, money you receive is positive. Rate and Nper must use the same period (monthly loan → rate/12, years×12).

FunctionSyntaxMeaning
PMT=PMT(rate, nper, pv, [fv], [type])Periodic loan payment (EMI). ₹10 L @ 9% for 15 yrs: =PMT(9%/12, 180, 1000000) → −₹10,142.67
FV=FV(rate, nper, pmt, [pv])Future value of an investment / recurring deposit.
PV=PV(rate, nper, pmt, [fv])Present value — today's worth of future cash flows.
NPER=NPER(rate, pmt, pv)Number of payment periods.
RATE=RATE(nper, pmt, pv)Interest rate per period.
NPV=NPV(rate, cf1:cfN) + cf0Net present value of future cash flows minus initial outlay; accept if NPV > 0.
IRR=IRR(cf0:cfN)Discount rate at which NPV = 0; accept if IRR > cost of capital.
IPMT / PPMT=IPMT(rate,per,nper,pv)Interest / principal portion of a specific payment — used in amortization schedules.

B6Data Consolidation

Consolidation (Data → Data Tools → Consolidate) combines data from multiple ranges/worksheets/workbooks into one summary using a function (Sum, Count, Average, Max, Min…).

  • By position: all source ranges have identical layout — cells are combined by their location (Jan, Feb, Mar sheets with the same structure).
  • By category: layouts differ — check "Top row" and/or "Left column" labels so Excel matches by label names.
  • Create links to source data → consolidated sheet updates automatically and shows an outline.
  • 3-D reference alternative: =SUM(Jan:Mar!B2) sums cell B2 across all sheets from Jan to Mar.

Preparing data for consolidation: each range on a separate sheet, same labels spelled identically, no blank rows/columns inside ranges, each range formatted as a proper list (labels in first row/column), and preferably name each range (Formulas → Define Name).

B7Extracting Values — Convert Text to Columns Wizard

Data → Text to Columns splits one column of combined text into several columns in 3 steps:

  1. Choose file type: Delimited (fields separated by characters) or Fixed Width (fields aligned in columns with spaces).
  2. Set delimiters (Tab, Semicolon, Comma, Space, Other) or click to place column-break lines.
  3. Set column data formats (General, Text, Date) and the destination cell → Finish.

Example: "Sharma, Priya, Bengaluru" with comma delimiter → three clean columns. Alternative formula-based extraction: LEFT/MID/RIGHT + FIND (Unit I), or Flash Fill (Ctrl+E) which learns the pattern from one example.

B8What-If Analysis

What-If tools (Data → Forecast → What-If Analysis) answer "what happens to the result if inputs change?" Three tools — know all three:

ToolDirectionUse case
Scenario ManagerMany inputs → many named casesSave "Best / Worst / Likely" sets of input values; switch between them; produce a Scenario Summary report.
Goal SeekResult → one input (reverse)"Set cell B5 (EMI) to value 9000 by changing cell B2 (loan amount)." Works backwards for exactly one variable.
Data Table1 or 2 inputs → grid of resultsOne-variable: column of interest rates → EMI for each. Two-variable: rates × tenures grid. Uses Row/Column input cell.

B9Importing Data & the Data Model

Importing data into Excel (Data → Get & Transform / Get External Data)

  • From Text/CSV — delimiter preview, load or transform (Power Query editor).
  • From Web — paste a URL, Excel detects HTML tables.
  • From Database — Access, SQL Server; also from Workbook, XML, JSON.
  • Imported queries can be refreshed to pull the latest data — a connection, not a copy-paste.

Data Model

The Data Model is an in-memory database inside the workbook that can hold multiple tables connected by relationships (via common key columns), letting a single PivotTable analyse millions of rows across tables without VLOOKUP. Tick "Add this data to the Data Model" when creating a PivotTable, and define relationships via Data → Relationships or the PowerPivot diagram view.

B10PowerPivot, Power View & KPIs

Exploring data with PowerPivot

  • Add-in providing an advanced interface to the Data Model: import huge datasets (limited only by memory), create relationships in Diagram View, add calculated columns and measures using DAX (Data Analysis Expressions), e.g. Total Sales := SUM(Sales[Amount]).
  • Enable via File → Options → Add-ins → COM Add-ins → Microsoft PowerPivot.

Exploring data with Power View & aesthetic reports

  • Interactive report/dashboard canvas: tables, matrices, cards, charts, tiles, slicers and maps on one sheet; visuals cross-filter each other on click.
  • Aesthetic reports: apply themes/backgrounds, tile visuals by category, use images and card layouts — presentation-ready interactive reports.

Key Performance Indicators (KPIs)

A KPI is a quantifiable measure of performance against a target. In PowerPivot a KPI has three parts:

  1. Base value — a calculated measure (e.g., Total Sales).
  2. Target value — another measure or an absolute number (e.g., Sales Target).
  3. Status thresholds — bands rendered as icons (red / yellow / green) showing performance vs target.

C1Overview of R & Environment Setup

R is an open-source programming language and environment for statistical computing and graphics, created by Ross Ihaka and Robert Gentleman (University of Auckland, 1993), an implementation of the S language. Maintained by the R Core Team; distributed via CRAN (Comprehensive R Archive Network).

Features (write any 6 in exams)

  • Free, open-source, cross-platform (Windows/Linux/macOS).
  • Interpreted language — commands run directly at the > prompt.
  • Rich built-in statistical functions (regression, hypothesis tests, time series…).
  • Excellent graphics — publication-quality plots.
  • 19,000+ extension packages on CRAN.
  • Vectorised operations; connects to C/C++/Python/databases; strong community.

Environment setup with RStudio

  1. Install R from cran.r-project.org (the engine).
  2. Install RStudio (posit.co) — an IDE on top of R with four panes: Source (scripts, top-left), Console (bottom-left), Environment/History (top-right), Files/Plots/Packages/Help (bottom-right).

Basic commands

# assignment (<- preferred, = also works)
x <- 10;  y = 5
print(x + y)          # 15
getwd()               # current working directory
setwd("C:/data")      # change directory
ls()                  # list objects in memory
rm(x)                 # remove object
help(mean); ?mean     # documentation
class(y)              # "numeric"

C2Variables & Data Types

R has dynamic typing — a variable's type is decided by the value stored, checked with class(). Valid names: letters, digits, dot, underscore; must start with a letter (or dot not followed by a digit).

R-objects built from these: Vector, List, Matrix, Array, Factor, Data Frame. A list can hold mixed types (list(1,"a",TRUE)); a data frame is a table whose columns can differ in type — the workhorse for datasets.

C3Control Structures

Decision making

marks <- 78
if (marks >= 90) {
  print("Grade S")
} else if (marks >= 75) {
  print("Grade A")
} else {
  print("Grade B or below")
}

# switch — matches a value against cases
day <- "wed"
result <- switch(day, mon="Start", wed="Midweek", fri="Weekend soon")
# vectorised one-liner:
ifelse(marks >= 40, "Pass", "Fail")

Loops

# for — iterate over a vector
for (i in 1:5) { print(i^2) }

# while — repeat while condition TRUE
i <- 1
while (i <= 5) { print(i); i <- i + 1 }

# repeat — runs forever until break
i <- 1
repeat {
  print(i); i <- i + 1
  if (i > 5) break
}
# break exits the loop; next skips to the next iteration
Compare in one line
for = known number of iterations · while = condition tested before each pass · repeat = tested inside, needs break (runs at least once).

C4Vectors, Matrices, Arrays & Factors

Vectors — 1-D, same type

v <- c(10, 20, 30, 40, 50)   # c() combines
s <- 1:10                    # sequence
q <- seq(1, 10, by = 2)      # 1 3 5 7 9
r <- rep(0, 4)               # 0 0 0 0
v[2]        # 20  (indexing starts at 1, NOT 0!)
v[c(1,3)]   # 10 30
v[-1]       # drop first element
v[v > 25]   # logical filtering: 30 40 50
v * 2       # vectorised: 20 40 60 80 100
length(v); sum(v); mean(v); sort(v); rev(v)

Recycling rule: in c(1,2,3,4) + c(10,20) the shorter vector repeats → 11 22 13 24. Coercion: mixing types silently upgrades all — c(1,"a") becomes character.

Matrices — 2-D, same type

m <- matrix(1:6, nrow = 2, ncol = 3)          # fills by column
m2 <- matrix(1:6, nrow = 2, byrow = TRUE)     # fills by row
m[1, 2]      # row 1, column 2
m[ , 3]      # entire 3rd column
dim(m); t(m)                # dimensions; transpose
A + B; A * B                # element-wise
A %*% B                     # TRUE matrix multiplication
rowSums(m); colMeans(m)

Arrays — n-dimensional, same type

a <- array(1:24, dim = c(3, 4, 2))  # two 3×4 "layers"
a[2, 3, 1]   # row 2, col 3, layer 1

Factors — categorical data

g <- factor(c("M","F","M","F","F"))
levels(g)        # "F" "M" — the distinct categories
nlevels(g)       # 2
table(g)         # frequency count: F=3 M=2
# ordered factor for ordinal data:
sz <- factor(c("low","high","med"),
             levels = c("low","med","high"), ordered = TRUE)

Internally a factor stores integer codes + a levels attribute — memory-efficient and required by many statistical functions.

C5Functions & R Packages

# user-defined function with a default argument
area <- function(l, b = l) {   # default: square
  result <- l * b
  return(result)               # or just: l * b (last value auto-returned)
}
area(5, 3)        # 15 — positional arguments
area(b = 3, l = 5)# 15 — named arguments (order-free)
area(4)           # 16 — default used
  • Components: function name, arguments (formals), body, return value.
  • Built-in examples: sum(), mean(), max(), min(), sqrt(), paste(), print(), seq(), rep(), toupper(), nchar().
  • Lazy evaluation: an argument is evaluated only when actually used inside the body — a missing unused argument causes no error.

Packages

install.packages("ggplot2")  # download from CRAN (once)
library(ggplot2)             # load into session (each time; errors if absent)
require(ggplot2)             # same but returns FALSE instead of error
installed.packages(); search()  # installed vs currently loaded

A package = a bundle of functions + data + documentation stored in the library folder. Base packages (base, stats, utils, graphics) load automatically. Popular add-ons: ggplot2, dplyr, tidyr, readr, xml2/XML, rjson/jsonlite, readxl.

Rapid-Fire Q&A — test yourself

Click a question to reveal the answer. If you can answer all of these cold, you're exam-ready.

Name the 6 steps of the data analysis process in order.
Requirements Specification → Data Collection → Data Processing → Data Cleaning → Data Analysis → Communication.
Difference between FIND and SEARCH?
FIND is case-sensitive and rejects wildcards; SEARCH is case-insensitive and accepts ? and * wildcards. Both return the position of a substring.
Difference between SUBSTITUTE and REPLACE?
SUBSTITUTE replaces by matching content (old text → new text); REPLACE replaces by position (start character + length).
How does Excel store dates and times internally?
Dates as serial numbers counting from 1-Jan-1900 (=1); times as fractions of a 24-hour day (12:00 noon = 0.5). This enables direct arithmetic on dates.
Why must data be sorted before using the Subtotal command?
Subtotal inserts a summary row "at each change in" the grouping column — if identical values aren't adjacent (unsorted), each cluster gets its own subtotal and the grouping is meaningless.
VLOOKUP exact vs approximate match?
4th argument FALSE/0 = exact match (any order, #N/A if absent). TRUE/1/omitted = approximate — table's first column must be sorted ascending; returns the largest value ≤ lookup value (grade slabs, tax brackets).
Why is INDEX+MATCH preferred over VLOOKUP?
It can look left or right of the key column, doesn't break when columns are inserted/deleted (no hard-coded column index), and only scans two columns (faster on big data).
Four areas of a PivotTable field list?
Rows, Columns, Values (aggregations), Filters. Slicers/Timelines add visual filtering.
Three What-If analysis tools and their direction of reasoning?
Scenario Manager (many saved input sets → compare outcomes), Goal Seek (desired output → solves backwards for one input), Data Table (1 or 2 varying inputs → grid of outputs).
Consolidation by position vs by category?
By position: identical layouts, combined cell-by-cell. By category: differing layouts, matched using Top-row / Left-column labels (labels must be spelled identically).
What is the Data Model and why use it instead of VLOOKUP?
An in-memory database inside the workbook holding multiple related tables joined through key relationships; one PivotTable can then analyse across tables — handling millions of rows, faster and cleaner than lookup formulas.
Three components of a KPI in PowerPivot?
Base value (measure being tracked), Target value (measure or absolute number), Status thresholds (bands shown as red/yellow/green icons).
Who created R, and what is CRAN?
Ross Ihaka and Robert Gentleman (Univ. of Auckland, 1993), based on the S language. CRAN = Comprehensive R Archive Network — the repository of R distributions and 19,000+ packages.
List R's 6 atomic data types and 6 main R-objects.
Types: logical, numeric, integer, complex, character, raw. Objects: vector, list, matrix, array, factor, data frame.
for vs while vs repeat in R?
for — fixed iterations over a vector; while — condition checked before each pass (may run 0 times); repeat — infinite until break (runs at least once). next skips an iteration, break exits.
What is the recycling rule?
When two vectors of unequal length are combined in an operation, the shorter one is repeated (recycled) to match the longer: c(1,2,3,4)+c(10,20) → 11 22 13 24.
Difference between a matrix and a data frame?
A matrix is 2-D with ALL elements of one type; a data frame is a table whose columns may have different types (numeric, character, factor…) — the standard structure for datasets.
install.packages() vs library()?
install.packages("x") downloads the package from CRAN to disk — done once. library(x) loads it into the current session — every session. require() is like library() but returns FALSE instead of throwing an error.
Which functions read CSV, XML, JSON, Excel into R?
read.csv() (base); xmlParse()/xmlToDataFrame() from package XML; fromJSON() from rjson/jsonlite; read_excel() from readxl (or read.xlsx from xlsx).
Which chart for: distribution, outliers, trend, correlation, share?
Distribution → hist(); outliers/5-number summary → boxplot(); trend → plot(type="o")/line; correlation → scatterplot plot(x,y); share of whole → pie().
