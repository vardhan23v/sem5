A1

What is Data Analysis · The Five Types

Data analysis is the process of inspecting, cleaning, transforming, and modeling data to discover useful information, draw conclusions, and support decision-making. Raw data is noise; analysis turns it into insight — and Excel is the world's most widely used analysis environment because it puts storage (cells), computation (formulas), summarization (PivotTables), and communication (charts) in one grid.

The five types named in the syllabus

⛏️
Data Mining
FIND HIDDEN PATTERNS IN LARGE DATA

Discovering previously unknown patterns, correlations, and anomalies in large datasets using methods at the intersection of statistics, machine learning, and databases. Typical tasks: association rules ("customers who buy X buy Y"), clustering (grouping similar customers), classification, anomaly detection. Excel's contribution: PivotTable exploration, correlation analysis, and add-ins for larger jobs.

📊
Business Intelligence (BI)
DATA → DECISIONS FOR THE ENTERPRISE

The strategies and technologies that transform raw business data into actionable information for executives: dashboards, KPIs, scorecards, historical + current views of operations. BI answers "what is happening in my business?" Excel's Power Pivot, Power View, and Power BI grew directly out of this need.

📈
Statistical Analysis
DESCRIBE + INFER

Two halves: descriptive — summarize what the data says (mean, median, mode, standard deviation, frequency distributions, charts); inferential — use a sample to draw conclusions about a population (estimation, hypothesis tests, regression). Excel: AVERAGE, MEDIAN, STDEV.S, CORREL, the Analysis ToolPak.

🔮
Predictive Analytics
USE THE PAST TO FORECAST THE FUTURE

Builds statistical/ML models on historical data to predict future outcomes: sales forecasting, credit scoring, churn prediction, demand planning. In Excel: trendlines, FORECAST.LINEAR, TREND, moving averages, regression via the ToolPak. The output is a probability or estimate, not a certainty.

📝
Text Analytics
STRUCTURE FROM UNSTRUCTURED TEXT

Deriving patterns and meaning from textual sources — reviews, emails, survey comments, social media — via linguistic and statistical techniques: keyword frequency, categorization, sentiment. In Excel this begins with the text functions of §D1: extracting fields, standardizing case, splitting and cleaning strings so that unstructured text becomes analyzable columns.

A guaranteed short/long question: "Explain the types of data analysis." Give the definition + one business example + one Excel feature per type. The one-line separators: mining = unknown patterns, BI = business dashboards, statistical = describe/infer, predictive = forecast, text = unstructured → structured.

B1

Data Analysis with Excel & Advanced Data Analysis

Core (everyday) analysis toolkit

  • Formulas & functions — 450+ built-ins across math (SUM, ROUND), statistics (AVERAGE, COUNTIF, SUMIFS), lookup (VLOOKUP, INDEX/MATCH — detailed in Unit II), text (§D1), and date/time (§E1). Cell references make every result live: change an input, everything downstream recalculates.
  • Sorting, filtering, subtotals (§G1–H1) — organize and summarize without formulas.
  • Conditional formatting (§F1) — visual analysis directly in the grid.
  • Charts — column/bar, line, pie, scatter; the communication stage of the process (§C1).
  • Tables (Ctrl+T) — structured ranges with auto-expanding formulas, header filters, and banded rows; the professional starting point of any analysis.

Advanced analysis toolkit

  • PivotTables / PivotCharts — drag-and-drop summarization of thousands of rows by any combination of categories (Unit II deep-dive).
  • What-If analysis — Goal Seek (find the input for a target output), Data Tables (1/2-variable sensitivity), Scenario Manager (named input sets).
  • Analysis ToolPak — add-in for regression, histograms, ANOVA, correlation, descriptive statistics batches.
  • Solver — optimization (maximize/minimize a target under constraints).
  • Power Query (Get & Transform) — import from files/databases/web, clean and reshape repeatably.
  • Power Pivot & the Data Model — millions of rows, related tables, DAX measures; Power View for interactive report canvases.
"Differentiate data analysis and advanced data analysis in Excel" → basic = formulas + sort/filter/CF/charts on one sheet; advanced = Pivot family, What-If, ToolPak/Solver, Power Query/Pivot handling scale, automation, and modeling. Name two tools each.

WORKED SCENARIO · college placement analysis 1 Requirements: "Which skills correlate with higher placement packages for CSE 2025?" — need per-student rows: CGPA, skills, package, company. Consumer: training & placement cell. 2 Collection: placement-cell register (xlsx) + student survey (Google Form CSV) + company offer letters. 3 Processing: import both into one workbook; one row per student; consistent column headers. 4 Cleaning: TRIM stray spaces in names, PROPER-case them, standardize "c++/CPP/Cpp", convert text-numbers to numeric packages, remove duplicate roll numbers, handle blanks. 5 Analysis: AVERAGEIF package by skill, CORREL(CGPA, package), PivotTable company × branch, scatter chart. 6 Communication: one-page dashboard: top-5 skills bar chart + key numbers, sent as PDF. Every exam answer on "the process" should carry a mini-scenario like this — it converts a definition list into an application answer.
Cleaning before requirements is wasted work — you can't know what "clean" means until the question fixes which fields matter and at what granularity. The order of stages carries the marks; don't shuffle it.

Solved extraction problems — the exam patterns

P1 · Split "KUMAR, RAVI" into first and last name Last = LEFT(A1, FIND(",",A1)−1) → "KUMAR" First = TRIM(MID(A1, FIND(",",A1)+1, 100)) → "RAVI" Pattern: FIND locates the delimiter → LEFT/MID cut around it → TRIM tidies. 100 = "rest of the string" trick. P2 · Extract the domain from ravi.k@nitte.edu = MID(A1, FIND("@",A1)+1, LEN(A1)) → "nitte.edu" P3 · Fix numbers imported as text with commas: "1,23,450" = VALUE(SUBSTITUTE(A1,",","")) → 123450 (now SUM-able) P4 · Build an ID: first 3 letters of name + "-" + year = UPPER(LEFT(A1,3)) & "-" & TEXT(B1,"0000") → "RAV-2025" P5 · Count words in a cell = LEN(TRIM(A1)) − LEN(SUBSTITUTE(TRIM(A1)," ","")) + 1 words = spaces + 1; SUBSTITUTE deletes spaces so the LEN difference counts them.
TRIM does not remove non-breaking spaces (CHAR(160)) common in web data — SUBSTITUTE(A1,CHAR(160)," ") first. And SUBSTITUTE ≠ REPLACE: one targets content, the other targets a position. Mixing them up is the most common lost mark in this section.

Dates & Times

The single idea everything rests on: Excel stores dates as serial numbers — day 1 = 1-Jan-1900, and each day adds 1 (so arithmetic on dates is ordinary subtraction). Times are fractions of a day: 0.5 = 12:00 noon, 0.25 = 6:00 AM. A cell showing "20-Aug-2026" and one showing 46254 can hold the same value — only the format differs.

F1

Conditional Formatting

Conditional formatting (CF) changes a cell's appearance automatically based on its value (or a formula) — analysis you can see without reading a single number. Rules live with the range and re-evaluate on every change. Home → Conditional Formatting.

  • Highlight Cells Rules — greater/less than, between, equal to, text contains, a date occurring, duplicate values.
  • Top/Bottom Rules — top/bottom N or N%, above/below average.
  • Data Bars — in-cell bar proportional to value: instant bar chart inside the grid.
  • Color Scales — 2- or 3-color gradient across the range: heat map.
  • Icon Sets — arrows/traffic lights/flags bucketing values into 3–5 bands.
  • Formula-based rules — "Use a formula to determine which cells to format": any TRUE/FALSE expression, e.g. highlight whole rows with =$C2>70 (note the mixed reference: column locked, row free).

G1

Sorting & Filtering

Sorting rearranges rows by one or more keys; filtering hides rows that fail criteria (they're hidden, not deleted). Data tab → Sort / Filter.

  • Single-level sort — A→Z / Z→A on one column; Excel auto-expands the selection so rows stay intact.
  • Multi-level sort — Data → Sort → Add Level: e.g. by Dept A→Z, then by Sales largest→smallest. Order of levels = order of tie-breaking.
  • Custom sorts — by cell/font color, by icon, or by a custom list (Jan, Feb, … instead of alphabetical Apr, Aug…).
  • AutoFilter — dropdown per header: check-lists, Text/Number/Date Filters (contains, between, above average, this month…), searchable.
  • Advanced Filter — criteria written in a separate range; supports AND (same criteria row) / OR (different rows) combinations and "copy result to another location" — the tool behind §H1-style reporting and unique-value extraction.
SORT & FILTER SANDBOX — click any column header to sort (again to reverse); filter by department
Name Dept Sales ₹k
Sorting a selection of one column while its neighbors stay put scrambles the records permanently — always let Excel expand the selection (or work inside a Table). Filtering hides rows: a plain SUM still adds the hidden ones — the §H1 SUBTOTAL function exists precisely to fix this.

H1

Subtotals with Ranges

The Subtotal feature (Data → Outline → Subtotal) inserts summary rows for each group in a sorted range plus a grand total, with collapsible outline levels (1/2/3 buttons). Iron rule: sort by the grouping column first — Subtotal breaks a group at every change in that column's value.

  • Dialog choices: At each change in (the sorted group column) · Use function (Sum, Count, Average, Max, Min…) · Add subtotal to (which columns get the summary). "Remove All" undoes everything.
  • The inserted rows use the SUBTOTAL function: SUBTOTAL(function_num, range) — 1=AVERAGE, 2=COUNT, 3=COUNTA, 4=MAX, 5=MIN, 9=SUM; codes 101–111 additionally ignore manually hidden rows.
  • Two superpowers of SUBTOTAL over plain SUM: it ignores rows hidden by a filter (a live total for whatever is visible), and it ignores other SUBTOTALs in its range — no double counting when nesting.
