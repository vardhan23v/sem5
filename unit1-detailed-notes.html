§1What is Data Analysis?

Definition · why it matters · data vs information

Data Analysis is a process of inspecting, cleaning, transforming and modelling data with the goal of discovering useful information, informing conclusions, and supporting decision-making.

Break the definition into its four verbs — each maps to a stage you'll study in §4:

  • Inspecting — examining data to understand its structure, quality and completeness.
  • Cleaning — removing errors, duplicates, inconsistencies and irrelevant records.
  • Transforming — converting data into a suitable format (splitting columns, changing case, converting text-dates into real dates).
  • Modelling — applying formulas, statistics or charts to extract meaning.

Data vs Information vs Insight

MeaningExample
DataRaw, unorganised facts78, 45, 92, 66 (marks of students)
InformationProcessed, organised data with context"Class average = 70.25"
InsightActionable conclusion"Section B needs remedial classes in Unit 3 topics"
Why Excel first?
Before Python/R at scale, Excel teaches every analysis concept — storage (grid), computation (formulas), summarisation (PivotTables), presentation (charts) — with zero programming. Roughly 750 million people use it; it remains the world's most common analysis tool.

§2Types of Data Analysis

Data Mining · Business Intelligence · Statistical Analysis · Predictive Analytics · Text Analytics — each = definition + techniques + example + tools

2.1 Data Mining

Data Mining is the process of discovering hidden patterns, unknown correlations, anomalies and useful knowledge from large datasets, using methods at the intersection of artificial intelligence, machine learning, statistics and database systems. It is sometimes called KDD — Knowledge Discovery in Databases.

  • Common techniques: classification (assign a category), clustering (group similar records), association-rule mining (X is bought with Y), anomaly/outlier detection, regression.
  • Example: market-basket analysis — a retail chain mines billions of transactions and finds "customers who buy diapers frequently buy baby wipes", so the two are shelved together.
  • Other applications: credit-card fraud detection (anomalies), customer segmentation for marketing (clustering), loan-default prediction (classification).

2.2 Business Intelligence (BI)

Business Intelligence is the set of strategies and technologies that transform raw data into meaningful and useful information for business analysis — dashboards, scorecards, reports — so managers can make tactical and strategic decisions.

  • Focus: mostly descriptive — "what happened / what is happening", presented visually.
  • Typical components: data warehouse → ETL (extract-transform-load) → OLAP cubes → dashboards/reports.
  • Example: a management dashboard showing this month's revenue by region, top 10 products, and inventory turnover, refreshed daily.
  • Tools: Power BI, Tableau, Qlik — and Excel itself via PowerPivot/Power View (Unit II).

2.3 Statistical Analysis

Statistical Analysis is the collection, exploration, interpretation and presentation of data using the science of statistics, to uncover patterns and trends and to quantify uncertainty.

BranchGoalTechniquesExample
Descriptive statisticsSummarise the data you HAVEMean, median, mode, range, variance, standard deviation, frequency tables"Average marks = 70.2, SD = 8.5"
Inferential statisticsConclude about a POPULATION from a sampleHypothesis testing, confidence intervals, regression, ANOVAPredicting an election result from a 10,000-voter exit poll

Excel support: functions such as AVERAGE, MEDIAN, MODE.SNGL, STDEV.S, VAR.S, CORREL, plus the Analysis ToolPak add-in (descriptive statistics, histogram, regression, t-tests).

2.4 Predictive Analytics

Predictive Analytics uses historical data + statistical algorithms + machine learning to estimate the likelihood of future outcomes. It answers "what is likely to happen?"

  • Techniques: regression models, time-series forecasting, decision trees, neural networks.
  • Examples: forecasting next quarter's sales from 5 years of history; predicting which customers will churn; predicting machine failure from sensor data (predictive maintenance); credit scoring.
  • Excel support: TREND(), FORECAST.LINEAR(), FORECAST.ETS(), trendlines on charts, Forecast Sheet (Data → Forecast).

2.5 Text Analytics

Text Analytics (text mining) is the process of deriving high-quality, structured information from unstructured text, using linguistic, statistical and machine-learning techniques.

  • Steps: collect text → clean/tokenise → extract features → analyse patterns → interpret.
  • Techniques: sentiment analysis, keyword/entity extraction, topic modelling, document categorisation.
  • Example: classifying 50,000 product reviews as positive/negative/neutral to find the most complained-about feature.

§3Excel as an Analysis Tool — the essentials

Workbook anatomy · references · formula rules you must not get wrong
  • Workbook = the file (.xlsx); worksheet = one grid tab; cell = intersection of a column (A, B, C…) and row (1, 2, 3…), addressed like B7; range = rectangular block like A1:C10.
  • Every formula begins with =. Operators: + - * / ^ and & (text join); comparisons = <> < > <= >= return TRUE/FALSE.
  • Relative reference A1 — adjusts when copied. Absolute $A$1 — frozen (press F4). Mixed $A1 / A$1 — one axis frozen. This distinction drives conditional-formatting formulas in §7.
  • Fill handle — drag the small square at a cell's corner to copy a formula/pattern down a column instantly.
Useful shortcuts for this unit
Ctrl+Shift+L toggle filters · Ctrl+T create Table · Ctrl+Q Quick Analysis · Ctrl+E Flash Fill · F4 cycle reference types · Ctrl+; insert today's date.

§4The Data Analysis Process — six stages in depth

Requirements → Collection → Processing → Cleaning → Analysis → Communication
1 Requirements→ 2 Collection→ 3 Processing→ 4 Cleaning→ 5 Analysis→ 6 Communication

⟲ Analysis often loops back to Collection/Cleaning when more or better data is needed — the process is iterative, not strictly linear.

Stage 1 — Data Requirements Specification

Decide what data is necessary, driven by the questions the analysis must answer. Specify: the population under study, the variables to measure (e.g., age, income, marks), their units, and the required accuracy/time period. Getting this wrong wastes every later stage.

Example: to analyse student performance you specify — population: all 3rd-semester CSE students; variables: USN, subject, CIE marks, SEE marks, attendance %; period: current academic year.

Stage 2 — Data Collection

Gather the specified data from identified sources. Data must be accurate, relevant and trustworthy.

  • Primary sources — collected first-hand: surveys, questionnaires, interviews, experiments, sensors.
  • Secondary sources — already existing: organisational databases, government records, websites, published reports.

Stage 3 — Data Processing

Organise raw collected data into an analysable structure — typically rows (records) × columns (fields) in a worksheet or database table. Includes data entry, digitising paper forms, merging files, and arranging one record per row with one variable per column.

Stage 4 — Data Cleaning

Detect and correct (or remove) incomplete, duplicate, inconsistent or erroneous records so results aren't misleading. Typical operations:

  • Remove duplicate rows (Data → Remove Duplicates).
  • Fix inconsistent text — extra spaces, mixed case, glued values (→ text functions, §5).
  • Handle missing values — delete, fill, or flag.
  • Correct wrong types — text-numbers to numbers (VALUE), text-dates to dates (DATEVALUE).
  • Check ranges — no marks > 100, no negative ages.
The 80/20 truth
Analysts commonly report spending the majority of project time on cleaning and preparing data — which is why this unit devotes so much attention to text and date functions.

Stage 5 — Data Analysis

Apply techniques to understand, interpret, and derive conclusions: formulas and statistics (averages, correlations), visual exploration (charts, conditional formatting), summarisation (subtotals, later PivotTables). Findings may reveal that more data or more cleaning is needed → iterate.

Stage 6 — Communication

Report results to decision-makers in the format they need: tables, charts, dashboards, written summaries. Good communication uses visualization — colour coding, data bars, well-chosen charts — so the message is clear at a glance to a non-technical audience.

5.5 The dynamic-split pattern (very common exam question)

Split A3 = "Ravi Kumar" into first and last name for any name length:

First name — everything before the space:
=LEFT(A3, FIND(" ", A3) - 1)                     → "Ravi"

Last name — everything after the space:
=MID(A3, FIND(" ", A3) + 1, LEN(A3))            → "Kumar"

Why it works: FIND(" ",A3)=5 → LEFT takes 4 chars; MID starts at 6;
LEN(A3) as length is "more than enough", MID just returns what exists.

§6Text Functions with Dates & Times

Serial-number system · date functions · time functions · text↔date conversion patterns

6.1 How Excel stores dates and times

  • A date is a serial number: 1 = 1-Jan-1900, 2 = 2-Jan-1900, … so "05-Aug-2026" ≈ 46,239. Because dates are numbers, =B1-A1 directly gives days between two dates, and dates sort/compare correctly.
  • A time is a fraction of a day: 06:00 = 0.25, 12:00 = 0.5, 18:00 = 0.75. A date-time like "05-Aug-2026 18:00" = 46239.75.
  • Formatting only changes the display — the underlying serial number is unchanged. (Format Cells → Number → Date/Time/Custom.)

6.4 Text functions WITH date/time values — the syllabus patterns

Pattern 1 · Text containing a date → real date

A1 = "Joined on 12/05/2023"
=DATEVALUE(MID(A1, 11, 10))      → serial 45058 → format as Date → 12-05-2023

Pattern 2 · Text containing a time → real time

A1 = "Shift starts 09:30 AM"
=TIMEVALUE(MID(A1, 14, 8))       → 0.3958 → format as Time → 9:30 AM

Pattern 3 · Date → text (for messages/joins)

="Report generated on " & TEXT(TODAY(), "dd-mmm-yyyy")
→ "Report generated on 05-Aug-2026"
Without TEXT you'd get "Report generated on 46239" — the raw serial!

Pattern 4 · Rebuild a date from a non-standard string

A1 = "20260805"  (yyyymmdd, common in exported files)
=DATE(LEFT(A1,4), MID(A1,5,2), RIGHT(A1,2))   → 05-08-2026
Rule of thumb
Going text → date/time: DATEVALUE / TIMEVALUE (or rebuild with DATE). Going date/time → text: TEXT with a format code. Format codes: dd, mm, mmm, mmmm, yy, yyyy, hh, mm, ss, AM/PM.

§7Conditional Formatting

Conditional Formatting automatically applies formatting — cell fill, font colour, borders, icons — to cells that satisfy a condition. The format is dynamic: change the value and the formatting updates itself. Purpose: make patterns, trends, and exceptions visible instantly.

7.2 Applying a basic rule — step by step

Procedure (write in exams)
1. Select the range (e.g., C2:C31, the marks column).
2. Home → Styles → Conditional Formatting → Highlight Cells Rules → Less Than.
3. Enter 40; pick a format ("Light Red Fill with Dark Red Text") or Custom Format.
4. OK — failing marks are now red, and stay red-aware as values change.

7.3 Formula-based rules — the powerful one

The formula is written as if for the top-left cell of the selection and must return TRUE/FALSE; Excel copies it across the range following relative/absolute reference rules.

Goal (selection)FormulaWhy the $ matters
Highlight ENTIRE row where marks in C < 40 (select A2:F31)=$C2<40$C locks the column so every cell in the row tests column C; row 2 stays relative so each row tests its own C.

7.4 Managing rules

  • Manage Rules… — view all rules on a sheet, Edit, Delete, and reorder with ▲▼. Rules are evaluated top-down; when formats conflict, the higher rule wins.
  • Stop If True — halt evaluation of lower rules once this rule matches.
  • Clear Rules — from selected cells or the entire sheet.

§8Sorting

Single-level · multi-level · custom lists · colour sort · pitfalls

8.1 Single-level sort

Click any cell in the column → Data → A→Z (ascending) or Z→A (descending). For numbers the buttons read Smallest→Largest; for dates, Oldest→Newest. Excel auto-detects the surrounding data region and keeps rows intact.

8.2 Multi-level sort

Procedure
1. Data → Sort (dialog opens).
2. Tick "My data has headers" so column names appear (and don't get sorted as data).
3. Sort by: Department (A→Z) → Add Level → Then by: Salary (Largest→Smallest).
4. OK. Rows group by department; within each department, highest salary first.

8.3 Custom & special sorts

  • Custom list: Sort dialog → Order → Custom List — sort Jan, Feb, Mar… or Low/Medium/High instead of alphabetical order. (Own lists: File → Options → Advanced → Edit Custom Lists.)
  • By colour/icon: Sort On → Cell Color / Font Color / Cell Icon — pairs beautifully with conditional formatting.
  • Left-to-right sort: Sort → Options → "Sort left to right" to sort columns instead of rows.
  • Case-sensitive: Sort → Options → tick Case sensitive.
Pitfall to mention
Selecting a single column before sorting can sort ONLY that column, scrambling rows (Excel warns "expand the selection" — always expand). Safest: click one cell, let Excel detect the region, or convert to a Table (Ctrl+T) first.

§9Filtering

AutoFilter · text/number/date filters · Advanced Filter with criteria ranges

9.1 AutoFilter

Data → Filter (Ctrl+Shift+L) adds a drop-down arrow to every header. Filtering hides non-matching rows (blue row numbers indicate a filtered state) — nothing is deleted. Each dropdown offers:

  • Checkbox list of unique values with a search box — tick what to keep.
  • Text Filters: Equals, Contains, Begins With, Ends With, Does Not Contain, Custom (with wildcards ? and *).
  • Number Filters: Greater Than, Between, Top 10 (items or %), Above/Below Average.
  • Date Filters: Today, This Week, Last Month, This Quarter, Year to Date, Between, All Dates in Period.
  • Filter by Color — by cell fill or font colour.

Filters on multiple columns combine with AND logic (a row must pass every column's filter). Clear with Data → Clear, or remove all arrows with Ctrl+Shift+L again.

9.2 Advanced Filter

For complex criteria (especially OR across different columns) and for extracting results elsewhere. Requires a criteria range: a copy of the header row + condition rows beneath it.

HI
1DeptSalary
2IT>50000
3HR

Reading the criteria: conditions on the same row are AND-ed; conditions on different rows are OR-ed. So the range above means: (Dept="IT" AND Salary>50000) OR (Dept="HR").

Procedure
1. Build the criteria range (H1:I3 above), headers spelled exactly like the data's headers.
2. Data → Sort & Filter → Advanced.
3. Choose action: "Filter the list, in-place" or "Copy to another location" (give a destination cell).
4. List range = your data; Criteria range = H1:I3.
5. Optional: tick "Unique records only" to remove duplicates in the output. → OK.

§10Subtotals with Ranges

Data → Outline → Subtotal · the SUBTOTAL function · outline levels · nested subtotals

10.1 The Subtotal command

Automatically inserts summary rows (subtotals) for each group of a sorted list, plus a grand total, and builds a collapsible outline on the left.

Procedure (memorise the 3 dialog choices)
1. SORT the list by the grouping column first — e.g., sort by Region. (If not sorted, identical values aren't adjacent and each cluster gets its own subtotal.)
2. Click inside the data → Data → Outline → Subtotal.
3. At each change in: Region · Use function: Sum · Add subtotal to: ✔ Sales.
4. Options: "Replace current subtotals", "Page break between groups", "Summary below data". → OK.
5. Use outline buttons 1 / 2 / 3: 1 = grand total only, 2 = subtotals, 3 = all detail rows. Remove All button clears everything.

10.2 The SUBTOTAL function

=SUBTOTAL(function_num, ref1, …)

Three properties that make SUBTOTAL special:

  1. It ignores other SUBTOTAL results inside its range — the grand total never double-counts the subtotal rows.
  2. With any function number it ignores rows hidden by a filter — so =SUBTOTAL(9, B2:B100) on filtered data totals only the visible rows (SUM would total everything).
  3. The 100-series additionally ignores manually hidden rows.
Nested subtotals
To subtotal by Region AND by Product: sort by Region then Product → run Subtotal for Region → run Subtotal again for Product but UNTICK "Replace current subtotals". Outline gains a 4th level.

★End-to-End Worked Example

One dirty dataset through the whole unit — this is how the pieces fit together

Scenario: the office exports an employee file. Column A holds messy combined text like " ravi kumar|IT|12/03/2021|45000 ". Task: produce a clean, analysed report.

  1. Clean the raw text: =TRIM(CLEAN(A2)) → "ravi kumar|IT|12/03/2021|45000".
  2. Split the fields (formula route; Text-to-Columns with "|" delimiter works too): 
    Name : =PROPER(LEFT(B2, FIND("|",B2)-1))                          → Ravi Kumar
Dept : =MID(B2, FIND("|",B2)+1, FIND("|",B2,FIND("|",B2)+1) - FIND("|",B2) - 1)  → IT
Date : =DATEVALUE(MID(B2, FIND("|",B2,FIND("|",B2)+1)+1, 10))      → 12-03-2021
Salary: =VALUE(RIGHT(B2, LEN(B2) - FIND("|",B2,FIND("|",B2,FIND("|",B2)+1)+1)))  → 45000
  3. Derive columns: Years of service =DATEDIF(D2, TODAY(), "y"); joining month name =TEXT(D2, "mmmm").
  4. Conditional formatting: data bars on Salary; formula rule =$F2<1 to shade rows of employees with < 1 year of service; Duplicate Values on Name to catch double entries.
  5. Sort: multi-level — Dept (A→Z), then Salary (Largest→Smallest).
  6. Filter: AutoFilter → Number Filter on Salary → Top 10; or Advanced Filter criteria (Dept="IT" AND Salary>40000) OR (Dept="HR").
  7. Subtotal: already sorted by Dept → Data → Subtotal → at each change in Dept, Sum of Salary → collapse to level 2 for a one-line-per-department payroll summary.
  8. Communicate: the level-2 view + data bars + a title "Payroll generated on " & TEXT(TODAY(),"dd-mmm-yyyy") = the report.

Notice the pipeline mirrors §4 exactly: processing → cleaning → analysis → communication.

Formula for first name from "Ravi Kumar" in A1?
=LEFT(A1, FIND(" ", A1) - 1) → "Ravi".
FIND("S","Data Science") vs SEARCH("s","Data Science")?
FIND is case-sensitive → 6 (capital S). SEARCH is case-insensitive → 6 as well for "s" (first s/S at position 6); but FIND("s",…) → 11. Know which is case-sensitive: FIND.
Replace only the 2nd hyphen in "a-b-c"?
=SUBSTITUTE("a-b-c", "-", "/", 2) → "a-b/c" — the optional instance argument.
Count commas in A1?
=LEN(A1) − LEN(SUBSTITUTE(A1, ",", "")).
TEXTJOIN's advantages over CONCATENATE?
Takes a delimiter once, accepts whole ranges, and can ignore empty cells (=TEXTJOIN(", ", TRUE, A1:A5)).
The serial number of 1-Jan-1900? Of 12:00 noon?
1; noon = 0.5 (times are fractions of a 24-hour day).
Formula for age in completed years from DOB in A1?
=DATEDIF(A1, TODAY(), "y").
Convert "Joined 12/05/2023" (date starts at char 8) to a real date?
=DATEVALUE(MID(A1, 8, 10)) — then format the cell as a date.
Why multiply (logout − login) by 24?
The difference of two times is a fraction of a day; ×24 converts it to hours.
Conditional-formatting formula to colour a whole row when C-column marks < 40?
Select A2:F31, New Rule → formula =$C2<40. $ locks column C; relative row lets each row test its own value.
Which sort option orders Jan, Feb, Mar correctly?
Custom List sort (Sort dialog → Order → Custom Lists) — alphabetical would give Apr, Aug, Dec…
In an Advanced Filter criteria range, same row vs different rows mean?
Same row = AND; different rows = OR.
Why sort before using Subtotal, and which button shows only subtotals?
Subtotal fires "at each change in" the group column, so identical values must be adjacent. Outline level button 2 shows subtotals + grand total.
SUBTOTAL(9, range) vs SUM(range) on filtered data?
SUBTOTAL(9,…) totals only visible rows and skips other SUBTOTAL cells; SUM totals everything, hidden or not.
